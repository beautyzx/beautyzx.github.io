# Beauty 的故事森林

首頁以小說書架與小軟真實照片相簿為主，不列出舊文章。
照片可點開放大、用左右箭頭切換，並保留桌面／手機版排版。

舊文章保留在 `old/2026-10-06/post/`，閱讀頁使用與首頁共用的童話森林樣式。
舊資料入口為 `old/`。文章文字保留，舊網址持續導向。
改版前的完整原始網站保留在 `old/original-2026-10-06/`。

新增文章可由助手處理，或在 `posts/` 建立具有 title、category、tag、excerpt 的日期檔名 Markdown，再執行 `python build.py`。
文章會產生在 `post/`；要公開展示時再加入相應目錄，首頁不自動展示舊文章。
小說正文尚未公開。

首頁與小說封面是插畫；`assets/xiaoruan/` 是使用者提供的小軟照片的 WebP 版本，不含 EXIF。
